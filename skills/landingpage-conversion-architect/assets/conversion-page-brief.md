# Conversion Page Brief

Use this asset when a landing page needs a deliberate conversion narrative before layout or copy implementation.

## Offer framing

- Define audience, core promise, primary CTA, and biggest objection.
- State whether the page sells a product, service, lead capture, or qualification step.
- Record what proof the visitor needs earliest to trust the offer.

## Narrative structure

- Outline the section order from first impression to final CTA.
- Map where pain, mechanism, proof, objections, and reassurance should appear.
- Note how mobile and desktop should preserve the same conversion logic.

## Validation

- Check whether the page answers what it is, who it is for, and what to do next within seconds.
- Confirm proof is placed near doubt rather than isolated as decoration.
- Record what CTA behavior, analytics, or experiments should validate the design.
