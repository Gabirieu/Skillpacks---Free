# Execution Plan Template

Use this asset when a request needs a compact plan that is still concrete enough to execute immediately.

## Scope framing

- State the objective, constraints, and non-goals in one place.
- Record assumptions that are safe to make without blocking execution.
- Identify what evidence will prove the task is done.

## Execution shape

- List steps in dependency order rather than by topic.
- Separate blockers from nice-to-have follow-ups.
- Call out decisions that change sequencing or rollout.

## Validation

- Include tests, checks, or review points that confirm the work is trustworthy.
- Note rollback or fallback behavior if a step creates risk.
- End with the immediate next move.
