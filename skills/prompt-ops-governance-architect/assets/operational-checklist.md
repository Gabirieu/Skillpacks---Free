# Prompt Ops Governance Architect - Operational Checklist

## Discovery
- [ ] Gather current-state artifacts and owners.
- [ ] Capture constraints, dependencies, and assumptions.
- [ ] Define what must not break.

## Design
- [ ] Clarify boundary decisions and responsibilities.
- [ ] Document tradeoffs and alternatives.
- [ ] Confirm security, quality, and operational implications.

## Implementation
- [ ] Break the work into reviewable increments.
- [ ] Identify migration or rollout prerequisites.
- [ ] Align monitoring, support, and documentation changes.

## Validation
- [ ] Define measurable acceptance criteria.
- [ ] Run scenario tests for edge cases and rollback.
- [ ] Record evidence and final signoff expectations.
