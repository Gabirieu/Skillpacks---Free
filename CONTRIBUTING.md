# Sugestões e contribuições

Sugestões podem ser compartilhadas pela aba [Issues](https://github.com/Gabirieu/Skillpacks---Free/issues). As contribuições são opcionais e não implicam compromisso de análise, resposta, incorporação ou suporte.

Para facilitar a leitura de uma sugestão, indique a skill envolvida, o problema observado e uma proposta de melhoria. Não publique dados pessoais, credenciais ou informações internas de terceiros.

Ao propor alterações, preserve o arquivo `SKILL.md` de cada skill e mantenha válidas as referências aos materiais auxiliares. Arquivos sem finalidade demonstrável devem ser evitados.
