## Instalação em três passos

1. Acesse a [última versão](https://github.com/Gabirieu/Skillpacks---Free/releases/latest) e baixe o arquivo ZIP.
2. Extraia o pacote e copie as pastas que estão dentro de `skills` para o diretório de skills do Claude Code.
3. Abra uma nova sessão do Claude Code.

**Onde instalar:** no seu usuário (`~/.claude/skills/`) ou somente em um projeto (`.claude/skills/`). No Windows, o guia oferece o procedimento com PowerShell, sem necessidade de identificar seu usuário ou computador.

[**Ver instruções detalhadas para Windows, macOS e Linux →**](docs/INSTALLATION.md)

## Como usar

Após a instalação, descreva sua tarefa ao Claude Code. Por exemplo:

```text
Use /landingpage-conversion-architect para analisar a estrutura
e os pontos de melhoria desta página.
```

Cada skill possui suas próprias instruções e arquivos auxiliares. A invocação e o carregamento automático dependem da versão e da configuração do Claude Code.

## Sobre esta edição

O SkillPacks Free é uma coleção de materiais disponibilizados gratuitamente pela **FGDevs**. Os recursos são fornecidos no estado em que se encontram, sem promessa de resultados, garantia de adequação a finalidades específicas ou compromisso de suporte e atualizações.

Recomenda-se revisar os arquivos e scripts antes de utilizá-los em qualquer projeto.
